- 두 원격 저장소를 직접 내려받고, 작업 폴더의 CRLF 변환 영향을 피하기 위해 Git 원본 blob을 비교함.

| 결과 | 개수 | 내용 |

GitHub는 원본보다 나중 버전이다. 앨범이 17개에서 19개로 늘었고 ARCANA·FAKE OFF 커버 및 영상, カレンデュラ·クライノイド·燐華 재생 자료가 추가되어 있다. 미디어 우선 정렬, 앨범명·순서, 곡별 음량도 달라져 있었다. 따라서 기존 main을 그대로 배포하면 Sites v19와 완전히 같은 동작은 아니었다.

기존 GitHub 후속 작업을 유지하면서 Sites 42개 파일의 **원본 바이트 전체**를 `snapshots/sites-v19/`에 별도로 보존했다. 모든 파일의 SHA-256·크기·기존 GitHub와의 관계는 `sites-v19-manifest.json`에 있다. snapshot의 42개 파일 해시와 참조 자산 존재 검사 통과.

추가/삭제·순서 저장 검증은 로컬 snapshot에서만 수행했다. 실제 Sites의 개인 커버·개인 순서를 변경하지 않았다. 실제 Sites 화면에서 기본 앨범 17개만 보였고 개인 추가 커버는 없었다.

`screenshots/sites-v19-live.jpg`와 `screenshots/sites-v19-restored.jpg`는 각 첫 화면 증거다. 창 높이가 서로 다르고 반사광·미세한 자세는 시간에 따라 바뀌므로 픽셀 동일성 비교는 하지 않았다. 모바일 전용 창 크기 검증은 수행하지 않았다. 전 곡의 음향 품질/음량을 청취 측정하거나 모든 GPU/브라우저를 시험한 것은 아니다. 원본 코드와 미디어 바이트는 모두 동일함을 검증했다.

## 복원 범위

GitHub만으로 원본 앱의 HTML·3D·커버·음원·영상·로직을 복원할 수 있다. Pages workflow의 source=`sites-v19`가 그 파일들을 직접 배포한다. 현재 자동 배포는 기존 후속 버전인 `dist/`를 계속 사용한다.

Sites의 로그인·접근 권한·도메인은 플랫폼 기능이며 복사 대상 파일에 포함되지 않는다. 개인 브라우저 저장 내용과 ChatGPT 프로젝트 대화 전체는 이 사이트 소스 백업의 범위가 아니다. 자세한 실행 방법과 주의사항은 [RESTORE.md](RESTORE.md) 참조.
